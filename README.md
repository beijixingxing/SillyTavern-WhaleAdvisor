# 参谋·鲸鲸 🐋

**SillyTavern 全局扩展 · 中文扩展**（界面与文档均为中文）

一个挂在酒馆右下角的「幕后参谋」悬浮窗，对**所有角色卡**生效：让主模型或自定义 API 给你下一步行动建议、把粗略想法润色成可直接发送的玩家输入、按需联网搜索佐证，然后一键发进剧情。

## 功能

- **🎯 问下一步**：结合当前卡的变量状态（自动读取 MVU stat_data，任何 MVU 卡通用）与最近剧情，给出 2~3 条带数字的可执行建议——每条建议都是一个可点击按钮，**点哪条只发哪条**
- **✨ 帮我完善**：把「想自研大模型」这类粗略想法，按当前状态补全数字与细节，改写成第一人称的剧本式输入（动作=行为描述，台词=「」括起，不混淆）
- **🚀 直接发送**：结果可随意编辑，编辑后选项实时更新；以玩家身份发进聊天并触发回复
- **生成通道**：主 API（酒馆当前连接）/ 自定义 API（OpenAI 兼容：地址 + 密钥 + 拉取模型 + 测试连接）。密钥跟随账号存于服务器 settings.json
- **对话补全预设**：直接加载酒馆里的预设（含上传 JSON），按 prompt_order 组装，`assistant_prefill` 优先做输出引导防空输出；预设 JSON 带 `whale_advisor` 字段可整套覆盖三段模板
- **联网搜索**：四档模式（关 / 触发词 / 智能判断 / 每次都搜），触发词可自定义增删；走 SillyTavern 服务端搜索中继（SearXNG），无跨域问题；Tavily 备选
- **双设置入口**：悬窗 ⚙️ 快速设置 + 扩展面板完整配置，实时同步；快捷键 `Alt+K` 唤起（Mac 为 `⌥ Option+K`）
- **移动端适配**：触屏拖动、桌面/手机 UI 模式切换自动重锚定右下角

## 安装

### 方式一：扩展面板安装（推荐）

1. 酒馆顶部 **扩展图标（魔法棒）** → **Install extension**
2. 粘贴本仓库地址，安装后刷新页面

### 方式二：手动放置（单用户）

把仓库文件放到对应目录后刷新页面：

```
SillyTavern/data/<你的用户名>/extensions/whale-advisor/
├── manifest.json
├── index.js
└── style.css
```

## 使用

1. 右下角 🐋 打开悬窗（或 `Alt+K`）
2. 想法丢进输入框 → **✨ 帮我完善** → 结果可编辑 → **🚀 直接发送**；留空直接 **🎯 问下一步**
3. 首次建议进扩展面板配置生成通道；不配置则默认走主 API，零配置可用

## 配置说明

| 配置 | 说明 |
|---|---|
| 生成通道 | 主 API = `generateRaw` 纯净通道（不带入卡片上下文，不会被角色设定带偏）；自定义 API = 直连 OpenAI 兼容端点 |
| 预设 | 从酒馆预设列表选择或上传 JSON；预设的 `assistant_prefill` 开启后优先于内置 `<<<JX>>>` 输出引导 |
| 联网搜索 | SearXNG 模式走 ST 服务端中继 `/api/search/searxng`（需 SillyTavern ≥ 1.12.6，实测 1.19）；在设置里填你自己的 SearXNG 地址（需开启 JSON 格式输出）；智能判断模式每次多一次轻量调用，由模型决定是否需要查证 |
| 提示词模板 | 三段可编辑（系统 / 问下一步 / 帮我完善），占位符：`{角色} {状态} {剧情} {想法} {搜索}`；可一键恢复默认 |

## 隐私与安全

- 无遥测、无统计、无第三方上报；所有生成/搜索请求只发往你自己配置的端点
- 自定义 API 密钥明文存于你服务器的 `settings.json`（与酒馆自身存储各家 API Key 同一信任边界），请勿在不可信的服务器上使用
- 悬窗位置记忆存于浏览器 localStorage，不含敏感信息

## 已知限制

- 会话中途新导入酒馆的预设需刷新页面才会出现在预设下拉
- 主 API 通道的采样参数跟随酒馆当前连接，不使用参谋加载预设里的参数
- 自定义 API 端点需允许浏览器跨域（CORS）；被拦截时状态行会明确提示
